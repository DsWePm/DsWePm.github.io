首页的开场是一块被雨打湿的白色楼板，板上有一道裂缝，往下是挤满了防盗网、空调外机和晾晒衣物的楼宇峡谷。往下滚动，镜头就掉进去。

这篇记录它是怎么搭起来的。

## 城市：全部用脚本生成

整座城没有一个手摆的物件。`build_city.py` 用一个随机种子，沿裂缝两侧一层一层地铺单元：窗洞、防盗网、空调、雨水管、晾衣杆。每个单元先占位，后放的东西读取已占的区间，所以空调不会再插进防盗网里，水管也会绕开它们。

```python
def free_u(fr, L):
    """a spot along the facade that nothing else has claimed yet"""
    for _ in range(12):
        u = rng.uniform(0.15, L - 0.15)
        if not any(a - 0.1 < u < b + 0.1 for a, b in fr.busy):
            return u
    return None
```

墙面的配色参考了城寨的老照片：褪色的蓝、粉、米、绿灰泥，盖在脏混凝土上；窗里的光有钨丝黄、冷白灯管、偏绿的灯管，还有透过红色和玫瑰色窗帘的光。

> 颜色的杂乱感不靠饱和度，而是靠**很多种低饱和的颜色挤在一起**。

## 衣服：解算一次，到处复用

晾晒的衣物是真正的布料解算。但不可能每根晾衣杆都解算一遍，所以只解算 8 个变体：3 件挂在衣架上的 T 恤（不同风力）、2 张搭在杆上的床单、2 张夹子夹着的床单、1 条毛巾。解算完把网格冻结，之后所有实例共享同一份网格，只换材质和缩放。

| 变体 | 数量 | 解算耗时 |
| --- | --- | --- |
| T 恤 | 3 | 约 40 s / 件 |
| 床单 | 4 | 4–5 s / 张 |
| 毛巾 | 1 | 1 s |

## 镜头：绑在一个会掉的物体上

最早的镜头是关键帧插值，看起来像电梯。后来改成直接积分一个下落物体：重力、二次空气阻力（终端速度 55 m/s）、指向落点的水平拉力，再加一个随速度平方增大的气动回正力矩。镜头只是跟着它。

![下落过程中的一帧](hero/fall/f_0100.webp)

撞地时速度约 34.9 m/s。最后几帧地面填满整个画面，于是页面在全黑的那一刻切到档案页，用一段字符瀑布衔接。

## 接回网页

- 254 帧 1920×1080 的 WebP，60 fps，共 21 MB，滚动直接对应帧号
- 静帧阶段是可交互的：深度视差、雨水涟漪、手机上用陀螺仪
- 雨是单独渲染的循环视频，在网页里作为折射叠加，而不是直接加白
