![囹圄](https://www.bilibili.com/video/BV1D841167Rs)

## 设定

近未来，基于量子的时空摄影机诞生。研究所的人员希望借此发掘古早的秘密，但是看到了一些难以解释的现象……

## 制作

| 部分 | 工具 |
| --- | --- |
| 竹林、房屋、锁链等资产建模 | Houdini |
| 部分资产 | Quixel Bridge、3d66 网 |
| 人物 | DAZ |
| 人物服装（参考 MD 官方汉服） | Marvelous Designer |
| 竹林雨打、竹叶上的雨水、锁链摆动 | Houdini |
| 落花 | Niagara |
| 雨水与天空 | Ultra Dynamic Sky |
| 衣物摆动解算 | Marvelous Designer |

- 竹叶上的雨水在画面里偏暗，可能不太看得出来
- 竹林的风格参考了 Leo Torres 的 [ArtStation 作品](https://www.artstation.com/artwork/04oqvY)
